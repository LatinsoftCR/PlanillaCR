PROMPT MAESTRO ERP PLANILLAS CR
Quiero desarrollar un sistema ERP de planillas para Costa Rica utilizando SQL Server y PHP.La arquitectura debe ser enterprise, altamente escalable, multiempresa y orientada a minimizar mantenimiento futuro.REGLAS IMPORTANTES:1. TODO debe ser parametrizable.2. Nunca quemar reglas legales en código.3. Todo cálculo legal debe depender de tablas de parámetros con vigencias.4. El sistema debe soportar:   - multiempresa   - multisucursal   - centros de costo   - destajos   - salarios fijos   - comisiones   - jornadas especiales   - incapacidades   - liquidaciones   - vacaciones   - aguinaldo   - SICERE   - integración bancaria   - integración contable   - workflow aprobación5. SQL Server debe contener:   - tablas   - índices   - vistas   - funciones   - stored procedures   - auditoría   - históricos   - snapshots legales6. PHP solo manejará:   - UI   - AJAX   - DataTables   - autenticación   - reportes7. Toda lógica fuerte debe vivir en SQL Server.8. Todas las tablas deben incluir:   - Estado   - FechaCreacion   - UsuarioCreacion   - FechaModificacion   - UsuarioModificacion9. Toda operación crítica debe registrarse en bitácora.10. El sistema debe estar preparado para crecimiento futuro aunque inicialmente no se utilicen todos los módulos.11. Todos los nombres deben ser consistentes y empresariales.12. Utilizar buenas prácticas SQL Server 2012+.13. Evitar recalcular históricos; usar acumulados y snapshots.14. Las vistas deben facilitar frontend y reportes.15. Los SP deben ser desacoplados y reutilizables.Cuando generes módulos:- crea estructura completa- relaciones- índices- vistas necesarias- funciones necesarias- SP necesarios- recomendaciones futuras- consideraciones legales CR- optimización- auditoría- seguridad
